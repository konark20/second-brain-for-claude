# Active Session Lock (advisory)

> Only matters if more than one assistant (for example Claude and another AI app, or two Claude sessions) has write access to this vault. Nothing here is enforced by the operating system. It works by discipline, like every other rule in this vault.

## Before writing anything

1. Read this file right after FOUNDATION, USER_PROFILE and BOUNDARIES.
2. If a session is marked ACTIVE below and it is not you, do not write. Reading is fine.
3. If none is active, add one line: tool, start time, intended scope.
4. When you finish, set it back to "None active" and log one line to today's journal.
5. A stale ACTIVE line from a previous day is not silently cleared. Note it in the journal and favour read-only work until the owner confirms.
