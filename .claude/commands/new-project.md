Create a project hub for the name after /new-project.

1. Slugify the name (kebab-case). If 01-Projects/<slug>/ exists, open its _hub.md instead and stop.
2. Copy 99-Meta/templates/project-hub.md to 01-Projects/<slug>/_hub.md and fill title and date.
3. Ask three questions: what does done look like, is there a real deadline, which agents or skills from 99-Meta/SKILL_MAP.md apply. Write the answers into Goal, Status and "Agents and skills assigned".
4. Hand off to the librarian agent to tag and index it.
Report: project ready -> 01-Projects/<slug>/_hub.md.
