# 01-Projects

Active work with a defined outcome and an end. One subfolder per project, each with a `_hub.md` made from `99-Meta/templates/project-hub.md`. Say "new project <name>" or run `/new-project <name>`.

Projects that run the ticket pipeline get a `tickets/` subfolder with `TICK-NNN.yaml` files. Finished or dormant projects move to `04-Archives/`.

See `examples/` in the repo root for filled-in samples.
