| `sample-owner/BOUNDARIES-owner-section.md` | Owner-specific rules for client confidentiality |
| `sample-owner/_hub.md` | A project hub with agents and skills assigned |
| `sample-owner/TICK-001.yaml` | A ticket after architect and builder have filled it |
| `sample-owner/2026-10-05.md` | A daily journal entry with carried-over items and a pattern note |
| `sample-owner/PATTERN_LOG-excerpt.md` | Three rows of the same shape, ready for skill-creator |
