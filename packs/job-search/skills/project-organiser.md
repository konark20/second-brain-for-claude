# Project Organiser

One job: every piece of work lives in a box with buckets and tags, so tailoring is a lookup, not an archaeology dig.

## Buckets

Define 3 to 6 buckets that match the roles you apply for (for example: strategy, operations, research, engineering, data). A project can sit in up to three buckets with a different lead angle for each.

## Box format (in PROJECT_BANK.md)

Name, period, status (complete, in progress, planned), one-line summary, buckets with per-bucket angle, tags, real numbers available with source, numbers missing, source artifacts (folder, drive, repository), draft bullets per bucket, public link if any.

## Rules

- Archive first, then bank, then inventory. The archive holds the full story; the bank holds resume-ready boxes.
- Missing detail becomes a question for the owner, not a guess.
- Incomplete projects carry their true status; a resume only claims the finished part.
- Uploaded source material is copied into the project folder so it persists, then catalogued.
