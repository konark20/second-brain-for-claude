# Optional packs

Sub-brains you can add on top of the core. Each pack is a coordinator agent (where needed), its specialist skills, and starter rule and template files. Install only what you use; the core works without any of them.

| Pack | For | Agents | Skills |
|---|---|---|---|
| [job-search](job-search/) | Applying for jobs, programs, fellowships | job-coordinator, dossier-keeper | jd-decoder, project-organiser, bullet-writer, number-miner, resume-layout, resume-critic, interview-defender |
| [linkedin](linkedin/) | Keeping a professional profile accurate and findable | linkedin-strategist | linkedin-keyword-mapper, linkedin-bio-writer, linkedin-post-writer, linkedin-photo-review |
| [trading](trading/) | Running a discretionary trading book with rules | none | strategy-builder, event-backtest, payoff-check, session-cadence, tilt-guard, conviction-override, scenario-analysis, trade-analysis, performance-analysis, retrospective-writer |

Each pack README has install steps and the rows to add to `99-Meta/SKILL_MAP.md`. Full explanations: [docs/packs.md](../docs/packs.md).
